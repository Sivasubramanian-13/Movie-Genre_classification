# Movie Genre Classification

This project classifies movies into genres based on their plot summaries using machine learning and natural language processing (NLP).

## Features

* Text preprocessing and cleaning
* Movie genre prediction from plot summaries
* Machine learning model training and evaluation

## Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP

## Installation

1. Clone the repository.
2. Install the required dependencies.
3. Run the application or model.
